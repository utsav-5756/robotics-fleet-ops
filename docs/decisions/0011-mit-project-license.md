# ADR 0011: MIT project license

- Status: accepted
- Date: 2026-10-28

## Decision

Release the project under the MIT License. The license permits public portfolio use, modification, and redistribution while requiring preservation of the copyright and permission notice.

## Consequences

- The repository includes the full license text in `LICENSE`.
- ROS package metadata declares `MIT`.
- The copyright holder is populated from the configured Git author name; ROS maintainer metadata uses the configured GitHub noreply address.
- This decision does not publish the repository or grant permission to reuse third-party assets beyond their own licenses.
